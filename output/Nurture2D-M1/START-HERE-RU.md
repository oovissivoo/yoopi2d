# Yoopi2D для Mac M1 — подготовленный исходный код

Целевой компьютер: Apple M1, macOS Sequoia 15.5.

**Это комплект для сборки, а не готовый проверенный `.app`.** Правки и состав
исходников проверены в Windows. Компиляция и запуск на macOS пока не выполнены.
Первый запуск скрипта на Mac покажет, нужны ли дополнительные исправления.

## Как собрать

1. Перенесите `Nurture2D-M1-build-kit.zip` на Mac и распакуйте в «Загрузки».
2. Откройте «Терминал».
3. Вставьте команду:

   ```sh
   /bin/bash "$HOME/Downloads/Nurture2D-M1/build-macos.command"
   ```

   Если распаковали в другую папку: введите `/bin/bash `, перетащите файл
   `build-macos.command` в окно Терминала и нажмите Enter.

4. Если появится установка Command Line Tools, завершите её и повторите команду.
   Полный Xcode из App Store для этого сценария обычно не требуется.
5. Скрипт установит Homebrew, если его ещё нет, затем Qt 5 и FFmpeg.
   Установщик Homebrew может попросить пароль администратора и нажатие Enter.
   Во время ввода пароля символы не отображаются — это нормально.
6. Дождитесь окончания. При успешной сборке откроется `dist/Yoopi2D.app`.
   Его можно перетащить в «Программы».

Нужны интернет, несколько гигабайт свободного места и время на первую сборку.
Homebrew и зависимости устанавливаются в `/opt/homebrew`; скрипт не заменяет
существующие приложения. Старые сборки и журналы сохраняются.

## Что проверить после запуска

- Нарисовать несколько штрихов, создать кадры и проиграть анимацию.
- Сохранить тестовый проект `.pclx`, закрыть и открыть его.
- Проверить импорт аудио и экспорт короткого видео/GIF.
- Если используете планшет — проверить нажим пера и горячие клавиши.

FFmpeg и ffprobe находятся через Homebrew даже при запуске из Finder.
Для этой локальной сборки оставьте `ffmpeg` установленным. Пакет `.app`
не проверен как автономная сборка для переноса на другие компьютеры.

## Если возникла ошибка

Не нужно начинать заново или удалять исходники. Пришлите последний файл из
папки `logs` рядом со скриптом и описание того, на каком шаге всё остановилось.
В журнале могут присутствовать имя пользователя и локальные пути.

Если macOS блокирует открытие локально собранного приложения, используйте
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»
для этой конкретной программы. Отключать защиту macOS целиком не нужно.
Сборка получает локальную ad-hoc подпись; сертификата разработчика Apple
и notarization в этом комплекте нет.

## Откуда исходники и что изменено

Источник: официальный архив автора
[Nurture2D-Source-2026.zip](https://github.com/nurture2d/nurture2d-Site/releases/download/v0.6.6/Nurture2D-Source-2026.zip).
Название архива — 2026, хотя он размещён в релизе с тегом `v0.6.6`.

SHA-256 исходного архива проверен:

```text
f094e8c3e17e7320d3ca82677f0a53190eb58ffc0ff4053270bf280a46377507
```

Из комплекта убраны готовые Linux-бинарники, старые результаты сборки, сайт
и файлы редакторов. Лицензии, код приложения, кисти, шрифты, иконки и переводы
сохранены.

Правки:

- ARM64 и минимальная macOS 15.0 заданы в скрипте явно.
- Генератор кистей собирается своим проектом qmake с правильными Qt frameworks.
- Linux-команда сборки генератора исключена из macOS-ветки `app.pro`.
- GNU-флаг линкера `-Wl,-s` больше не передаётся Apple linker.
- Старый недокументированный Carbon-вызов заменён уже имеющейся обёрткой NSEvent
  с сохранением прежнего выбора режима; зависимость от Carbon убрана.
- Исправлен регистр заголовка `AppKit.h` для файловых систем с учётом регистра.
- Исправлены тип пакета `APPL` и логическое поле Retina в `Info.plist`.
- Добавлен поиск FFmpeg/ffprobe в Homebrew при запуске из Finder.
- Добавлены сборка, упаковка Qt, локальная подпись, проверки ARM64/подписи
  и запуск `--version`. Эти проверки выполнятся при запуске скрипта на Mac.
- Ошибки, предупреждения и события Undo/Redo пишутся в
  `~/Library/Application Support/Nurture2D/Nurture2D/logs/yoopi2d.log`.

Список проверок, реально выполненных при подготовке, находится в `VALIDATION-RU.txt`.
