# Проверка переходов между рисунками на macOS

Проверка запускает настоящее окно MainWindow2 с временными INI-настройками и новым документом. Настройки и документы пользователя не используются. Нужны уже собранные объекты приложения и Qt 5 из Homebrew.

Из папки `<рабочая папка сборки>/application/app`:

```sh
task_source='/абсолютный/путь/к/исходникам/Nurture2D'
make -f Makefile -f "$task_source/tests/keyframe_navigation.mk" navigation-regression \
  "NAVIGATION_SOURCE=$task_source/tests/src/test_keyframe_navigation_integration.cpp"
QT_QPA_PLATFORM=offscreen DYLD_FRAMEWORK_PATH=/opt/homebrew/opt/qt@5/lib \
  QT_LOGGING_RULES='*.debug=false' ./navigation-regression-bin
```

Проверяются реальные QAction и кнопки таймлайна, стрелки, переходы между рисунками на кадрах 1, 6 и 14, пропуск ненумерованного ключа на кадре 3, остановка на границах, однократная обработка события, текстовый фокус и отключённое сочетание. Клавиатурные события содержат разные логические символы раскладок при одинаковых физических кодах macOS. Это проверка маршрутизации событий; она не переключает системную раскладку.

Необязательный аргумент — путь к новому тестовому `.pclx`: программа сохранит туда три рисунка для ручной проверки в приложении. Без аргумента документ не сохраняется.
